# MeFit presentation outline

- **0–10 min:** Introduce the team, then explain the requirements, identity and API boundaries, schema, release decisions, and the hardest implementation issues.
- **10–20 min:** Demonstrate registration and MFA, profile setup, goal completion, contributor authoring, and administrator approval using prepared accounts. Rehearse each role before the presentation.
- **20–30 min:** Discuss ownership, validation, backups, performance evidence, and trade-offs. Leave time for questions and defend the decisions with test results.
